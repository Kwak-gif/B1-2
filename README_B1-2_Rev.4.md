## 6. 사용 도구 목록 + 선택 이유

### T2I / I2V 선택 기준 
- **T2I(텍스트→이미지)**: 정지컷 제작에 사용. 장점=구도 정밀 제어, 단점=움직임 없음.
- **I2V(이미지→영상)**: 완성 이미지에 움직임 부여 시 사용. 장점=캐릭터 일관성 유지, 단점=크레딧 소모 큼.
- **선택 원칙**: 본 프로젝트는 **T2I(제미나이)로 3씬 이미지 확정 후 → I2V(오픈AI) 또는 CapCut 슬라이드쇼**로 영상화 (캐릭터 일관성 우선).

### 도구 간 통합 보정 절차
1. **해상도 통일**: 전 이미지 9:16(1080×1920)로 생성/리사이즈.
2. **색감 보정**: CapCut 필터로 3씬 톤 통일 (밝기·채도 일괄 적용).
3. **불일치 시**: CapCut → 조정(Adjust)에서 씬별 색온도 수동 보정 후 재확인.

### 크레딧 부족 시 우선순위 (체크리스트)
1. ☐ **씬 축소**: 3씬 → 2씬(후킹+CTA) 우선 유지.
2. ☐ **도구 교체**: 유료 영상 생성 → 무료 이미지 슬라이드쇼(CapCut).
3. ☐ **편집 대체**: 움직임을 CapCut 트랜지션·줌 효과로 보완.
